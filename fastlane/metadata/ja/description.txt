「抹茶マップ（MatchaMap）」は、世界の抹茶ファンのための発見・記録・図鑑アプリです。東京、京都、ソウル、ニューヨーク、ロンドン、パリ — どの街でも本物の抹茶カフェに、ひとつのアプリで出会えます。

[ 主な機能 ]
• グローバル地図 — Google Maps SDKベースのなめらかな街ズーム、抹茶ピン、クラスタリング。
• カフェ詳細 — メニュー、価格、営業時間、混雑時間、経路、ストリートビューをワンスクリーンで。
• 抹茶図鑑 — 飲んだ抹茶をカードで集めて、等級・産地・色合い・テイスティングノートを記録。
• レビュー — 写真付きのひとことレビューとタグでカフェを共有。
• 友だちフィード — 友だちの図鑑とレビューを清潔なタイムラインで。
• ウィッシュリスト — 行きたいカフェを国別にまとめ、ミニ世界地図で表示。
• Apple／Passkeyサインイン — パスワード不要、安全。

[ 抹茶マップが選ばれる理由 ]
• 抹茶の色合いを5段階で評価 — Pale SpringからDeep Forestまで。色でカフェを比較できる初の体験。
• 産地を9分類 — 宇治、静岡、鹿児島、韓国、台湾など。葉の出身地でカフェを絞り込める。
• ミニ世界地図ウィッシュリスト — 旅行リストを世界の星座のように。

[ 多言語対応 ]
韓国語、英語（米・英）、日本語、ドイツ語、フランス語 — 6言語のフルローカライズ。旅先でも母国語で。

[ はじめかた ]
アプリを起動 → 位置情報を許可 → AppleまたはPasskeyで1秒サインイン。あなたの周りの抹茶カフェが地図に広がります。

抹茶マップは韓国 → 日本 → 米国 → 英国 → ドイツ → フランスの順で先行公開します。最初の60秒は広告を表示しません — 発見が先、広告は後です。
