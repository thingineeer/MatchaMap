## 출시 시퀀스 (사용자 직접)

1. 위 §A-§H 항목 모두 처리 (1-2일)
2. 시뮬레이터 매트릭스 풀 회귀 (qa-functional, 반나절) — 252 셀 중 P0 시나리오 7 × 디바이스 3 × 언어 6 = 126 우선
3. `bundle install`
4. `./scripts/setup-vault-symlinks.sh`
5. `bundle exec fastlane sync_certificates`
6. `bundle exec fastlane beta` — TestFlight 업로드 (`bump_build`로 빌드 번호 자동 갱신)
7. TestFlight 외부 테스터 5-10명 1주
8. 회귀 결함 수정 → `bundle exec fastlane beta` 재업로드
9. `bundle exec fastlane upload_metadata` (메타데이터 6언어 업로드)
10. `bundle exec fastlane submit_for_review` (자동 출시 옵션 활성화)
11. Apple 심사 24-72시간
12. 출시 후: `git checkout release && git merge --no-ff main && git tag v1.0.0 && git push --tags`
