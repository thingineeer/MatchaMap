# ICP — Ideal Customer Profiles

> Owner: `po-growth` · Last updated: 2026-05-04 · Confidence: 중 (PRD 가설 + 시장조사 기반 합성)

말차맵 v1.0.0의 3대 페르소나. 각각 **demographics · JTBD · behaviors · top 3 needs**를 정의. 이 페르소나는 모든 디자인·카피·기능 우선순위의 베이스라인이다.

---

## 페르소나 1 — 여행자 매니아 (Traveling Aficionado)

> 출장/여행 중에도 "진짜 매장"을 못 놓치는 사람. 글로벌 매출 견인.

### Demographics

| 항목 | 값 |
|---|---|
| 나이대 | 28–42세 |
| 성별 비중 | 여 60 / 남 40 |
| 직업 | 마케팅, 디자인, IT, 의료, 자영업 |
| 가처분소득 | 중상–상 (월 가처분 1.5K USD+) |
| 거주 도시 | 서울, 도쿄, 뉴욕, 런던, 베를린, 파리 (1선/2선 메트로) |
| 여행 빈도 | 연 4-12회 (국내 + 해외) |
| 디바이스 | iPhone 15+ / iPad 보유율 30% |

### JTBD

> "낯선 도시에 도착했을 때 5분 안에 *진짜 매장*을 찾아 시음하고 싶다."

서브-잡:
- "노포 vs 트렌드 카페 빠르게 식별하고 싶다."
- "현지인이 가는 곳 vs 관광객용 식별하고 싶다."
- "한정 메뉴/시즌 메뉴 놓치고 싶지 않다."

### Behaviors

- Google Maps에서 `matcha cafe near me`로 검색하지만 결과가 *카페+말차 메뉴*까지 섞여 만족도 낮음.
- Instagram에서 `#매차순례` `#matcha [city]` 해시태그로 사전 조사.
- Notion/Apple Notes에 다녀온 매장 메모 (도감 욕구 미충족).
- Google Maps Lists 활용하지만 *공유/소셜* 어려움.

### Top 3 Needs

1. **카테고리 정확도**: "말차 전문 / 차 전문 / 일반 카페-매차메뉴"를 즉시 분류해주는 필터.
2. **여행 모드**: 위치권한 외 *해외 도시 미리보기* (출장지 도착 전 검색).
3. **일관된 도감**: 매장 시음 후 자동/반자동 도감 등록 → 평생 기록.

### 말차맵 핵심 매치

PRD §3 Map + §4 Review + §5 Collection. 여행 모드 인터페이스는 `ios-map`이 *도시 검색바* + *해외 도시 핀턴 인디케이터*로 구현.

## 페르소나 2 — 로컬 도감러 (Local Collector)

> 자기 도시·동네에서 시음한 매차를 카드로 모으는 게 즐거움 자체. 리텐션의 핵심.

### Demographics

| 항목 | 값 |
|---|---|
| 나이대 | 22–35세 |
| 성별 비중 | 여 75 / 남 25 |
| 직업 | 학생(대학원 포함), 디자이너, 카피라이터, 프리랜서 |
| 가처분소득 | 중 (월 가처분 0.5–1.5K USD) |
| 거주 도시 | 서울 성수/연남, 도쿄 시모키타자와, NY Williamsburg, LDN Shoreditch, Berlin Mitte |
| 디바이스 | iPhone 13+ / 사진 정리 습관 강함 |

### JTBD

> "내가 마신 매차 한 잔 한 잔을 *기억하고 정리하고 자랑하고 싶다*."

서브-잡:
- "원산지/등급/색감/맛 비교를 카드로 한눈에 보고 싶다."
- "내 컬렉션이 다른 사람과 어떻게 다른지 보고 싶다."
- "100매 컬렉션 같은 도전 과제로 동기부여 받고 싶다."

### Behaviors

- 인스타에 `#매차도감` `#matchadiary` 일주일 1-2회 포스팅.
- 가스미가세키 보드 등 핀터레스트 무드보드.
- TikTok 매차 ASMR/언박싱 시청 (5.53% 평균 engagement, 매차맵 본 페르소나 핵심).
- 매장에서 *첫 한 모금 사진* 찍는 습관.

### Top 3 Needs

1. **수집욕 만족 UX**: 카드 그리드, 등급 컬러, 뱃지/어치브먼트.
2. **자랑 가능한 공유 아웃풋**: 인스타 스토리/릴 친화 *매차 카드 이미지 자동 생성*.
3. **취향 큐레이션**: 내 컬렉션 기반 추천 ("이 사람은 진한 코이차파").

### 말차맵 핵심 매치

PRD §5 Collection + §6 Social + 보상형 광고 (도감 잠금 해제). 보상형 광고는 *수집욕*을 결제 의지로 직결시키는 가장 자연스러운 슬롯.

## 페르소나 3 — 공유러 (Sharer)

> 내 발견을 *친구에게 자랑하고 함께 가기*가 핵심. 그로스 루프의 엔진.

### Demographics

| 항목 | 값 |
|---|---|
| 나이대 | 24–38세 |
| 성별 비중 | 여 70 / 남 30 |
| 직업 | 마케터, 콘텐츠 크리에이터, 인플루언서(마이크로) |
| 가처분소득 | 중–중상 |
| 친구 네트워크 | 인스타 팔로워 500–10K, 친한 친구 5-15명 |
| 디바이스 | iPhone 14+ |

### JTBD

> "내가 좋아하는 매장을 *친구에게 권유하고 함께 인증*하고 싶다."

서브-잡:
- "친구 위시리스트와 내 위시리스트를 합쳐 *함께 갈 코스* 짜고 싶다."
- "친구의 평점이 모르는 사람보다 신뢰도 높음."
- "추천이 *플레이스홀더 메모*가 아닌 *예쁜 카드*로 전달되길."

### Behaviors

- 인스타 DM/카톡으로 매장 링크 공유, 그러나 정보 단절(외부 링크 클릭 → 다시 구글맵).
- "어디서 봤지?" 검색 반복.
- 친구와 약속 잡을 때 *서로의 위시리스트*를 비교하고 싶음.

### Top 3 Needs

1. **카드 단위 공유**: 매장 카드 → 카톡/iMessage 공유 + 클릭 시 매차맵 딥링크.
2. **친구 위시리스트 동조화**: 친구 위시 + 내 위시 교집합 자동 추천.
3. **그룹 도감**: 친구 그룹의 합산 컬렉션·랭킹.

### 말차맵 핵심 매치

PRD §6 Social + §7 Wishlist. 그로스 루프 §3 (도감 공유 → 친구 가입)의 핵심 엔진. 공유 카드 OG 이미지는 v1.0.0 필수.

## 가설 매핑

각 페르소나가 어떤 [backlog.md](decisions/backlog.md) 가설 카드의 *주체*가 되는가:

| 페르소나 | 주체 가설 | 어떻게 검증되는가 |
|---|---|---|
| 1. 여행자 매니아 | **H1** (travel_mode=true 도감 등록률 ≥ 50%) | 위치권한 + 거주지 거리 ≥ 200km 자동 분류 → 그 세그먼트의 도감 등록률 측정. JTBD "낯선 도시에서 진짜 매장"이 *수집욕*으로 전환되는지의 직접 신호. |
| 2. 로컬 도감러 | **H10** (보상형 광고 시청 후 D7 retention +5pp), 부분적으로 **H3** (ARPU ≥ $0.05) | 도감 50매 한도 도달 시 보상형 광고 시청이 retention과 ARPU에 동시 기여. 페르소나 2가 도감 한도 도달 가장 빠른 그룹. |
| 3. 공유러 | **H2** (friend≥1 D7 ≥ 비친구 D7 × 2), **H5** (카드 공유율 25% / 클릭→가입 8% / 신규 중 공유 30%) | 친구 그래프 자연 발생 + 카드 OG 클릭 트래킹. 페르소나 3이 카드 공유 행동의 80% 이상 차지 가설. |

## 5 Forces / 블루오션 관점 (sc:business-panel 요약)

- **Christensen (파괴적 혁신)**: 일반 카페앱은 "발견"만 처리, 말차맵은 *발견+도감+소셜* 결합으로 *비소비자(말차 카드 모음을 노션으로 하던 사람들)*를 주류 사용자로 흡수. 클래식 disruption.
- **Porter 5 Forces**:
  - 경쟁자 강도: 낮음 (말차 전용 모바일 앱 부재)
  - 진입장벽: Google Places API + 큐레이션 데이터셋 + 도감 메타데이터(등급/원산지) 시드.
  - 대체재: Google Maps + Notion 조합 (높지만 통합되지 않음).
- **Kim & Mauborgne (블루오션)**:
  - 제거: 매장 등록 부담(v1.0.0 소비-only 모델), 광고 침해(60초/첫화면 차단).
  - 강화: 카드 도감, 공유 카드 OG.
  - 신규: 매차 등급 필터, 글로벌 여행 모드, 컬렉션 그룹 랭킹.
