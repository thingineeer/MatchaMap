# Growth Loops

> Owner: `po-growth` · Last updated: 2026-05-04 · 참조: `pm-go-to-market:growth-loops` 프레임워크
>
> 5개의 그로스 루프. 각 루프는 *입력 → 행동 → 산출 → 재투자* 의 4단계로 자체 강화. 우선순위는 v1.0.0 출시 시 즉시 작동 가능한 순서.

## 루프 1 — 도감 공유 → 친구 가입 (Viral Loop, **P0**)

> 핵심 그로스 엔진. 도감러 페르소나의 자발적 자랑이 신규 가입을 만든다.

### 메커니즘

```
[도감러] 매장 시음 → 매차 카드 생성
   → 카드를 인스타 스토리/카톡으로 공유 (OG 이미지 자동 생성)
   → 친구가 카드 클릭 → 매차맵 딥링크 → 앱스토어/앱 이동
   → 가입 후 *그 친구가 공유한 카드*가 첫 화면에 환영 카드로 노출
   → 친구도 그 매장 추가 → [도감러] 됨
```

### 핵심 메트릭

| 메트릭 | 목표 (출시 후 30일) |
|---|---|
| 카드 공유율 (공유 / 카드 생성) | ≥ 25% |
| 외부 클릭 → 가입 전환 | ≥ 8% |
| 신규 가입 중 *공유 링크* 비중 | ≥ 30% |

### 구현 의존성

- 매장 카드 OG 이미지 자동 생성 (Cloud Functions, `server-functions` 책임).
- iOS Universal Link / Custom Scheme 딥링크 (`ios-auth-monetize`).
- 공유 텍스트 6개 언어 (`qa-localization`).

## 루프 2 — 위시리스트 동조화 (Collaboration Loop, **P0**)

> 공유러 페르소나의 *친구와 함께 가기*를 자동화. 위시리스트가 친구 네트워크의 약속/만남을 만든다.

### 메커니즘

```
[사용자A] 매장 위시리스트 추가 (도시별 그룹)
   → [친구B] 공유러가 위시 카드 보고 "나도 가고싶다" 추가
   → 두 사람 위시리스트의 *교집합 매장* 생성 → "함께 가요" 카드 알림
   → 둘 중 누구든 방문 → 도감 등록 → 공동 도감(그룹 컬렉션)에 카운트
   → 그룹 도감 진척도 → 새 친구를 그룹에 초대 동기 부여
```

### 핵심 메트릭

| 메트릭 | 목표 (출시 후 30일) |
|---|---|
| 친구 1명+ 사용자 비율 | ≥ 25% (PRD §4 일치) |
| 위시 교집합 매장 평균 (친구 ≥1 사용자) | ≥ 3개 |
| 그룹 컬렉션 활성화율 | ≥ 40% |

### 구현 의존성

- 친구 그래프 (`server-data` Firestore subcollection).
- 푸시 알림 (`server-auth` FCM).
- 그룹 도감 화면 (`ios-social-collection`).

## 루프 3 — 리뷰 → 베스트 매장 → 신규 사용자 흡수 (Usage Loop, **P0**)

> 사용자가 만든 콘텐츠가 다음 사용자를 끌어당기는 표준 UGC 루프.

### 메커니즘

```
[사용자] 매장 시음 → 평점 + 사진 + 글
   → 매장 카드 평점/리뷰 수 ↑
   → "베스트 매차 [도시]" 자동 큐레이션 (주간/월간 리더보드)
   → 인스타 hashtag #말차맵 #MatchaMap 통한 자연 노출
   → 신규 사용자가 베스트 카드 발견 → 가입
   → 가입자가 새 매장 시음 → ...
```

### 핵심 메트릭

| 메트릭 | 목표 (출시 후 30일) |
|---|---|
| 사용자 평균 리뷰 수 | ≥ 1.2 |
| 베스트 카드 인스타 노출 (자연) | ≥ 1,000회/주 |
| 베스트 카드 클릭 → 앱 진입 전환 | ≥ 5% |

### 구현 의존성

- 매장 점수 알고리즘 (`server-functions`, 별도 ADR).
- 주간 자동 리포트 (Cloud Function 스케줄러, KST 월요일 09:00).

## 루프 4 — 보상형 광고 → 도감 무제한 → 사용 빈도 ↑ (Revenue Loop, **P1**)

> 수익화와 사용 빈도가 같은 방향으로 강화되는 루프.

### 메커니즘

```
[사용자] 도감 50매 한도 도달
   → "광고 시청 후 카드 1개 잠금 해제" 옵션
   → 보상형 광고 시청 (eCPM ~$15)
   → 카드 잠금 해제 → 매장 시음 → 도감 추가
   → 다음 카드 한도 도달 → 다시 광고 또는 *광고 제거 구독* 결심
```

### 핵심 메트릭

| 메트릭 | 목표 (출시 후 30일) |
|---|---|
| 보상형 광고 시청 / DAU | ≥ 0.15 |
| 광고 시청 후 D7 retention | ≥ 22% (시청 안한 사용자 대비 +5pp) |
| 보상형 → 구독 전환 (v1.1) | ≥ 1% |

### 구현 의존성

- 도감 한도 관리 (Domain 레이어).
- 보상형 광고 SDK (`ios-auth-monetize`).
- 카드 잠금 해제 애니메이션 (`designer-lead`).

## 루프 5 — 여행 모드 → 도시별 도감 → 다음 여행 동기 (Usage Loop, **P1**)

> 여행자 페르소나가 한 번 사용 시 다음 여행을 *예약하게 만드는* 루프.

### 메커니즘

```
[여행자] 도쿄 출장 중 5매장 시음 → 도쿄 도감 카드 5장
   → "도쿄 도감 진척 5/30" 인디케이터
   → "다음 여행지 추천" — 미니 세계지도에서 *도감 0인 도시* 강조
   → 여행 계획 시 사전에 *도쿄 미수집 25개 + 새 도시 위시리스트*
   → 새 도시 방문 → 도감 +N → 글로벌 진척도 ↑
```

### 핵심 메트릭

| 메트릭 | 목표 (출시 후 30일) |
|---|---|
| 여행자 D30 retention | ≥ 28% |
| 평균 사용자 도시 카드 수 | ≥ 1.8 |
| 미니 세계지도 클릭률 | ≥ 35% |

### 구현 의존성

- 미니 세계지도 (`ios-map`, Google Maps SDK 별도 뷰).
- 도시 도감 진척도 카드 (`ios-social-collection`).

## 루프 우선순위 매트릭스

| 루프 | 출시 시 활성화 | 임팩트 | 구현 난이도 | 우선순위 |
|---|---|---|---|---|
| 1. 도감 공유 → 가입 | v1.0.0 | 매우 높음 | 중 | **P0** |
| 2. 위시리스트 동조화 | v1.0.0 | 높음 | 중 | **P0** |
| 3. 리뷰 → 베스트 → 흡수 | v1.0.0 | 중 | 중상 | **P0** |
| 4. 보상형 → 도감 무제한 | v1.0.0 (보상형 슬롯만) → v1.1.0 (구독) | 중 | 낮 | **P1** |
| 5. 여행 모드 → 도시 도감 | v1.0.0 (단순) → v1.1.0 (추천) | 중 | 중 | **P1** |

## 측정 인프라 의존

- Firebase Analytics + Firestore 로그.
- 핵심 이벤트: `card_share_initiated`, `wishlist_match_created`, `review_submitted`, `rewarded_ad_completed`, `city_collection_progress_viewed`.
- `pm-data-analytics:cohort-analysis`로 D7/D30 cohort 비교 (출시 후).

## 가설 매핑

각 루프가 어떤 [backlog.md](decisions/backlog.md) 가설 카드를 검증·강화하는가:

| 루프 | 매핑 가설 | 어떻게 |
|---|---|---|
| 1. 도감 공유 → 가입 | **H5** (활성/PROPOSE: 카드 공유율 25% / 클릭→가입 8% / 신규 중 공유 30%) | 카드 공유 OG + 딥링크 클릭률을 직접 측정. P0이므로 v1.0.0 출시 시점 검증 시작. |
| 2. 위시리스트 동조화 | **H2** (friend≥1 D7 ≥ 비친구 D7 × 2) | 친구 1+ 사용자가 위시 교집합으로 retention이 ×2 이상 가는지. |
| 3. 리뷰 → 베스트 → 흡수 | (간접) **H3** ARPU + (간접) 자연 가입 트래픽 | 베스트 카드 SEO/오가닉 트래픽이 신규 가입의 30% 이상을 차지하는가는 별도 가설(H11) 후보. |
| 4. 보상형 → 도감 무제한 | **H10** (보상형 시청자 D7 +5pp) + **H3** (ARPU) | 보상형 광고 시청자 코호트의 retention과 광고 매출 동시 측정. |
| 5. 여행 모드 → 도시 도감 | **H1** (travel_mode 도감 등록률 ≥ 50%) | 여행자 세그먼트의 도감 등록률 + D30 retention 동시 측정. |
