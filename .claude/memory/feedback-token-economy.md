**규칙**:
1. **토큰 절약**: 같은 정보 반복 출력 금지. 스크린샷·툴 결과를 본문으로 다시 풀어쓰지 않는다. 결정과 다음 액션만 짧게.
2. **할루시네이션 방지**: 본 적 없는 파일/라이브러리/API/필드명을 추측해 작성 금지. 의심 시 Read/Bash로 검증 후 진행. 라이브러리/SDK 정보는 context7로 fetch.
3. **컨텍스트 70% 임계**: 컨텍스트 사용률이 ~70% 도달했다고 판단되면(시스템 알림 또는 누적 메시지 부피로 추정), 즉시:
   - 진행 중 결정·결과를 `.claude/memory/handoff-*.md`로 압축 저장.
   - 미완료 task를 TaskUpdate로 명확히 owner + 다음 액션 명시.
   - 사용자에게 짧은 진척 1줄 요약 후 새 세션 권장.
4. **답변 길이**: 사용자가 짧은 보고를 원하는 경향. 복잡한 계획·반복 표는 docs/ 또는 메모리로 옮기고 채팅엔 1~2 단락만.

**Why:**
- 사용자 명시: "토큰아끼는 skill도 잘 활용했으면 좋겠어 할루시네이션 안당하... compact도 한 70% 꽉차면 md파일 잘 정리후 작업하면 좋을듯".
- 16명 팀 + 다중 Phase 운영에 매 turn마다 모든 산출물 재나열은 컨텍스트 폭발의 원인.

**How to apply:**
- idle 알림이 다발할 때는 1~2 줄 ack만 + 침묵.
- 자동화 진행(예: Firebase 콘솔 클릭 시퀀스)은 batch로 여러 단계 묶고, 본문엔 결정·다음 단계만 1단락.
- 산출물 검증은 Bash 1~2건으로 압축. ls + 핵심 grep만.
- ADR/PRD 같은 문서는 docs/에 적고 채팅에는 경로 + 1줄 요지.
